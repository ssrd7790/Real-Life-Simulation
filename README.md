# জীবন সিমুলেটর — Bengali Life Sim

Immersive first-person life simulation in Bengali. The AI acts as Reality Engine / Dungeon Master / World Simulator — never as a chatbot.

## State model (authoritative, JS-side)
`sim = { id, name, city, controlledId, characters{}, persona, world{date,dayCount,timeMin,location,locationFacts,pulse}, stats{health,mood,satiety,energy}, finances{cash,bank,bills[]}, inventory[], relationships{}, npcs{}, memories{core,shortTerm,longTerm}, chronicle[], journal[] (+journalSeq/journalBeat/journalArchive/journalDropped/journalMigrated), income, storylines[], log[], historyCutoff, critical{active,sinceDay}, healthDrainAcc }` (fractional sub-1 physiology drains persist here; migrated default 0; `world.pulse` ≤220-char atmosphere line, migrated ""; `world.locationFacts` ≤200-char Bengali physical layout lock — rooms/floors/furniture/boundaries — backfilled by `defaultLocationFacts(location,socialClass)`, updated via `location_facts` patch).

- `persona`: `{name, age (legacy starting value), baseAge/baseDay (JS aging anchor), gender, occupation, socialClass, personality, background, traits (16-key numeric), traitLabels (display strings), states (8-key), romance? (adult-only), conditions[] (≤8 Bengali ≤80 each, body/mind states), experiences[] (≤12 Bengali ≤100 each, lived competence)}`. HUD/edit show `currentAge(sim) = baseAge + floor((dayCount-baseDay)/360)`; editing re-anchors (`baseAge=entered, baseDay=today`). Conditions render under ❤️ শরীর ও মন, experiences under 🧍 চরিত্র (existing CSS only); both travel in `/swap` sheets and patch via `conditions_add/remove` / `experiences_add` (normName dedupe).
- `npcs[id]`: `{id, name, role, age (number|null; null=unconfirmed), trust, familiarity, emotion, background, personality, publicPersona, privateReality, secrets, goals, core_traits, states, romance? (adult-only), mind{thought≤160,intent≤140,doing≤120} (player-invisible inner life, backfilled from privateReality/goals with zero PRNG drift), memory[], inactive, exitNote, exitDay}`. Seed ages: করিম চাচা 65, মালতী 38, মেহতা সাহেব 48, প্রিয়া 36, নাসিমা আপা 30, জাহাঙ্গীর 38, বাবা 62, তিথি 23.
- LLM proposes a **patch**; JS validates, clamps, applies. Numbers in narration never overwrite state directly. Validation: finite-number checks, 0–100 clamps, cash/bank ≥ 0 floors, string slices (names ≤60, notes ≤200, chronicle/core ≤220, etc.).
- Calendar: 1 sim year = 360 days; `simYear`/`currentAge`/`seasonForMonth`/`dayPhaseLabel(timeMin)` are JS-computed and surfaced in the prompt (phase: ভোর/সকাল/দুপুর/বিকেল/সন্ধ্যা/গভীর রাত + lighting truth). Never model-computed.
- Chronicle (`chronicle[]`, capped 120, prompt last ~40 entry-boundary budgeted ≤700 chars) + `memories.core` (capped 30, prompt ≤300 chars entry-boundary) are CANON; `longTerm` (capped 200) is sampled only as vague non-canon "faded echoes" (≤300 chars). Relevance-ranked dossiers (top 6, total ≤4000 chars, partitioned PRESENT vs OFF-SCREEN) + live-only CAST census (≤16, ≤600 chars) replace the old blind slice. The journal (`journal[]`, 400 live + 200 archive, `JOURNAL_OWN_KEYS` spread into applier `owns`) records every beat as a scored event (system-derived daily weather/money/health/roster + model-landing dual-writes); the prompt's ≤400-char FACTS block surfaces the scheduler's top-5 instead of raw recent-memory/echo dumps, and `rebuildChronicle` replays narrated canon exactly (V5). Dossier mind lines are labeled `[thought:] | [intent/schedule:] | [doing/whereabouts:]` (display slices 80/70/110 word-boundary, SOV-negation safe; full values live in sim) with stable id `- name (id) [role` + ` and [ON PHONE] marker; recent preserves >=2 direct memories (off-screen tagged).
- NPC registry hygiene: normalized-name dedupe on `npcs_add` (merge, never duplicate); `npcs_exit` sets `inactive` + `exitDay` (leaves CAST/dossiers, history kept); `storylines_close` sets `closedDay`; paid bills older than 30 sim-days are pruned (unknown `paidDay` kept).
- Economy (one payment path): `payBillByKey(sim,key)` settles **cash first, then bank for the remainder, atomically** (full amount or nothing; balances never below 0; correct `paidDay`). Both `bills_paid` (LLM patch) and `/pay` (player) route through it. Insufficient total → bill stays unpaid, balances untouched, console warning + short internal short-term memory note (narration not rewritten; next prompt's bills/finances tell the truth). Prompt instructs the model to send **no** `cash_delta`/`bank_delta` for the same bill; a patch that does both with negative deltas has them neutralized **up to the settled total** with a warning (partial duplicates charge once; any remainder above the bill total stays as a legitimate extra expense). `recurring_income{source,amount,cadence_days,lastPaidDay}` auto-credits on payday (survives model amnesia); `{"cleared":true}` ends it. Known behavior: a long gap credits **in full on the next turn that runs the routine** — one bounded batch (≤3650 paydays), `lastPaidDay` advancing idempotently per payday, so income is never lost and never double-credited on the following turn. Cash/bank floor at 0. Wealthy preset's ₹150,000 club fee (cash ₹50,000 + bank ₹2,000,000) is payable via `/pay`.
- Time: `timeMin` + `date DD/MM`; normal actions clamped 3–20 min; `/skip` allows up to 7 days + montage narration + top-up guarantee. Passive decay is applied **before** patch stats land (LLM landing state wins); effective decay hours are capped at 8 h on skips (routine survival assumed). `/skip` top-up advances leftover time via `advanceTime` then runs the same `creditRecurringIncome` + `prunePaidBills` moment (income never lost/doubled; decay not re-applied to landing stats).
- `/swap` (D3 personal vs shared): personal travels in the sheet (`persona` incl. age + traits/states/legally-applicable romance + conditions/experiences, `stats`, `finances`, `inventory`, `memories`, recurring `income`, personal `chronicle` view); shared stays in the sim (calendar/time, `location` + `pulse`, NPC registry, `relationships`, `storylines`). NPC→player carries over real age (never 30 for a known elder), traits/states/romance (adult-only), occupation/texture, and accumulated NPC memory seeded as first-person recollections; the NPC record is never deleted and never stashed — the controlled record carries `controlled=true` (cleared on leaving), the original player gains an `npc_<id>` record on first swap away and it is only flagged/unflagged thereafter. Leaving writes carried age/psych/memory back into that same persistent record (npc.mind untouched, preserved seamlessly); entering rebuilds persona from it with fresh `conditions[]`/`experiences[]`. CAST, dossiers (`rankedNpcs`/`liveNpcs`) and `applyPatch` targeting (`npc_states`/`npc_mind`/`npc_memory_add`/`relationships`, plus `npcs_add`/`npcs_exit` dedupe) all exclude the flagged record exactly as if absent (model addressing the controlled name is ignored with `console.debug`; HUD may keep an existing relationship row). Confirmed age <18 NPCs are never playable — `/swap` refuses with a Bengali system message before any state mutation. Player→NPC carries age/psych both ways. New strangers get deterministic defaults (`profileFor` + `baseStates`, never undefined traits). Model-facing history respects a POV boundary (`historyCutoff` + `controlledId` tags; on-screen log stays visible, model prompt excludes pre-swap POV with a seam line). Shared world time/location/NPCs/relationships/storylines stay shared by design. The link is stabilized by `sim.controlledNpcId` (set on swap-enter, cleared for record-less strangers; persona renames propagate to the linked record via `saveEdit`; `migrateSim` backfills/repairs it idempotently). Legacy `stashedNpc`/`stashedNpcId` saves migrate by restoring stashed records, de-duplicating same-name `npc_<id>` + original-id pairs (keep original id, merge psych/memory/mind), and re-flagging the current persona (or none).
- `/pay`: forgiving bill match (id/exact/normalized/includes), shared atomic routine, `paidDay` set, bank-aware, double-spend-proof against both cash and bank deltas. Insufficient total → narrated failed attempt, no deduction.
- Persistence: `root.kv.sims` (IndexedDB, per-user). `loadIndex` persists a save only when `migrateSim`/`hygienePass` actually changed it (snapshot compare), so steady-state boots never rewrite storage. Export/import JSON files for backup (imports are sanitized: strings coerced/capped, memory shapes normalized, reserved map keys dropped, numbers finite-checked; log HTML rebuilt safely from text). `jibon_active` goes through the crash-proof `store` wrapper (denied `localStorage` falls back to memory instead of throwing).
- Psychology (`src/personality.js`): each NPC has 16 stable `core_traits` (0-100), 8 temporary `states`, `romance?` **only if confirmed adult 18+** (never unconfirmed or `<18`; role/occupation labels never gate it) — model-only, HUD never shows numbers (fog of war). Each NPC also carries a player-invisible `mind{thought≤160,intent≤140,doing≤120}` (private feeling, agenda, off-screen activity) backfilled from `privateReality`/`goals` with zero PRNG drift; dossiers show a compact mind line and the model refreshes it via `npc_mind` (resolved via `resolvePersonKey`, controlled person ignored, strings sliced). Confirmed age <18 NPCs additionally carry `core_traits.lust=0` and `states.desire=0` architecturally (model values discarded on `npcs_add`/merge/migrate/decay; dossier text omits lust/desire keys for minors). `migrateSim`/`migrateNpc` backfill old saves (NPC `age:null` + strip romance for unconfirmed/minor, `mind` (labeled display), `world.pulse`, `world.locationFacts` via `defaultLocationFacts` (LOC_FACTS_MAX=200), persona `conditions`/`experiences`, `exitDay`, persona `states`/`baseAge`, `critical`, `historyCutoff`, legacy sheets/income/chronicle/`closedDay`/`lastDay`) without touching history; existing `profileFor` output unchanged (deterministic distinct profiles). Hot states decay with time in `applyPatch` **before** `npc_states` land; dominant-emotion label is derived from **final** states (≥60) so label and numbers never contradict. All characters 18+ JS-enforced where romance applies; explicit acts fade to black; attraction ≠ availability ≠ consent.

## JS plausibility rails (tunable constants at top of `src/engine.js`)
- `STAT_MAX_STEP_NORMAL=25`, `STAT_MAX_STEP_SKIP=60`: per-turn stat movement caps (hospital arc still recovers over several beats).
- `REL_MAX_STEP=15`: trust/familiarity move gradually (multi-scene 5→100).
- Windfall: `max(100000, wealth*2)` positive total without `chronicle_add` is clamped with warning; with a chronicle-worthy cause it passes. Ordinary wages/sales/loans and legitimate wealthy movements unaffected. Negative deltas exceeding balances are floored with a visible short-term memory note (never silently free).
- Physiology: satiety/energy landing at 0 erodes health at `1.0/hr` each (scaled by full elapsed time, after rate caps). Dual-zero (both at 0) caps at full `PHYS_DRAIN_DAILY_CAP=12`/24h while single-zero caps at half (`6`/24h), so starving alone drains strictly slower than starving while exhausted. Sub-1 drains persist in `healthDrainAcc` (fractional, integer-applied) so normal turns erode gradually instead of rounding to zero; per-patch drain is capped proportionally so any 24 h window loses at most `PHYS_DRAIN_DAILY_CAP=12` (one-day dual-zero lands 12, single-zero lands 6, never collapses). Health 0 → `critical={active:true,sinceDay}` + short-term memory + unmistakable `INCAPACITATED` line in authoritative state; clears only when health ≥20 via narrated recovery. No silent permanent death.

## Save hygiene (conservative: merge → compact → drop; all caps named at top of `src/engine.js`)
Per-patch flood limits (`PATCH_MAX_*`: short 10, chronicle 3, core 2, story 5, inventory 10, bills 5, NPCs 5, NPC-mem 5/key, exit 10, conditions 3 add / 3 remove, experiences 2, offscreen 5, mind 20 keys). End-of-`applyPatch` + post-migration `hygienePass`: storylines cap 50 (prune oldest **closed** by `closedDay`; active never auto-dropped); relationships merge duplicates by normalized person + cap 100 by relevance (never drop live-scene relationships); NPCs never deleted (long-inactive >90 d compacted to last 5 memory lines, identity/psych/mind/exit note kept); bills never delete/reduce unpaid (exact-duplicate unpaid `bills_add` skipped); inventory merged by normalized name + cap 120 distinct (drop lowest-qty oldest clutter beyond); conditions/experiences deduped by normalized name + capped (8 / 12, newest kept); world pulse sliced to 220. Normal-size saves are byte-identical through the pass. Worst-case save ordering: chronicle/core/storylines/relationships/inventory/NPC-memory hard-bounded; NPC identities/exit notes/active storylines/unpaid debts unbounded by design (canon/continuity).
